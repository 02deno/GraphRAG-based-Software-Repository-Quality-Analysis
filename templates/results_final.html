Every edge is directed (source → target by node id). Below is how each implemented edge type connects nodes in this extractor.

IMPORTS — File → File. The importing module file depends on another file that provides the resolved import.

IN_FILE — Function or Class → File. The symbol is defined inside that file.

CALLS — Function → Function or Class. A function body includes a statically extracted call-site targeting that symbol.

TESTS — Test → Function or Class. The test is statically linked to the symbol it targets (not a runtime coverage metric).

MODIFIED_BY — File → Commit. The file was changed by that commit (read from git log); only emitted when the working tree has a .git directory.

Node meanings: File = one Python module path; Function / Class = definitions; Test = extracted test entity; Commit = git commit (short hash + author + ISO date + subject).
